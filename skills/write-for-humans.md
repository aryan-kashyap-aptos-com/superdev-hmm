# Skill: Write for humans

Use when the text is for people: messages, emails, docs, PR descriptions, status updates, or when the user says "humanize".
Not for prompts, tool descriptions, or text another AI will read. For those, use `skills/write-for-ai.md`.

## Steps

1. Decide who will read it and what they must know or do after reading.
2. Put the main point in the first sentence.
3. Write the rest in the order the reader needs it.
4. Cut every sentence the reader would not miss.
5. Read it once as the reader. Fix anything that sounds like a template.

## Style

- Write like a competent colleague talking: direct, warm, specific.
- Mix short and medium sentences. Avoid long chains of clauses.
- Use concrete facts, numbers, and names instead of general claims.
- Use "I", "we", and "you" where they fit.
- Use lists only when items are truly parallel. Otherwise write sentences.
- Match the medium: a chat message is 1-3 sentences, an email has a clear ask, a doc has headings.

## Avoid

Words: delve, leverage, utilize, robust, seamless, crucial, pivotal, landscape, realm, tapestry, elevate, empower, streamline, foster, holistic, cutting-edge, game-changer, unlock, navigate (figurative), "in today's fast-paced world".

Patterns:
- "It's not X, it's Y." / "Not only X, but also Y."
- Three adjectives in a row.
- Opening with praise or a restated question ("Great question!").
- Closing with a summary of what you just said, or "Let me know if you have any questions."
- Emphasis on every other phrase (bold, exclamation marks).
- Hedging every claim ("it might potentially perhaps").

## Boundaries

- Never add facts that were not in the source.
- Never turn a guess into a certainty, or a certainty into a guess.
- Keep the author's meaning, names, and numbers exactly.
- Return only the rewritten text unless the user asks for notes.
