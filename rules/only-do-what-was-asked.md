# Rule: Only do what was asked

Do what was asked. Nothing more, nothing less.

## Before you start a non-trivial task

Write three short lines for yourself (and for the user if the task is big):

- **Task:** what the user wants, in one sentence.
- **In scope:** what you will change.
- **Out of scope:** what you will not touch.

## While you work

- No drive-by refactors, renames, or style fixes in code you were not asked to change.
- If you find another problem, mention it at the end. Do not fix it unless asked.
- If the task grows, stop and tell the user before you continue.
- If the request is unclear and a wrong guess is costly, ask one short question. If a wrong guess is cheap, pick the obvious option and say which one you picked.

## When you finish

Tell the user:

1. What you changed.
2. How you checked it.
3. Anything you noticed but did not do.
